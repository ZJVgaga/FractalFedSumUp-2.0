# FractalFedSumUp 2.0 - Ultra Clean Version

This is an ultra-clean, anonymous version of the FractalFedSumUp 2.0 federated learning framework.

## Features
- Multiple federated learning algorithms (FedAvg, FedProx, FedAdam, etc.)
- Fractal-based data compression
- Differential privacy mechanisms
- Batch experiment management with Excel configuration
- Visualization tools
- GPU monitoring
